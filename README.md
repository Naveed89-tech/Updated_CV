## ✨ Features
This isn't just a static page; it's built with clean code and modern practices:

* **Responsive Design:** Looks great on Mobile, Tablet, and Desktop.
* **Print Friendly:** Includes a `@media print` CSS block so it prints perfectly to PDF on A4 paper.
* **Semantic HTML:** Accessible and SEO friendly structure.
* **Clean UI:** Uses a minimal color palette for maximum readability.

## 🛠️ Tech Stack
* **Structure:** Semantic HTML5
* **Styling:** Modern CSS (Flexbox & Grid) 
* **Fonts:**  Inter (Google)
